记忆圣所 v0.2.11
==================

怎么玩
  安装完成后，从「开始菜单」或桌面快捷方式双击「记忆圣所」即可。
  不需要浏览器、不需要联网、不需要另装运行环境。

安装信息
  安装位置：默认 %LOCALAPPDATA%\Programs\MemorySanctuary（当前用户目录，不需要管理员权限）
  如果安装时提示缺少 WebView2 运行时，按提示装一下即可（Windows 10/11 通常已自带）。

卸载
  方式一：设置 → 应用 → 已安装的应用 → 记忆圣所 → 卸载
  方式二：开始菜单 → 记忆圣所 → 卸载 记忆圣所
  卸载时会问一句：是否同时删除存档与缓存？
    · 选「否」：保留存档，重装后接着玩（推荐）
    · 选「是」：彻底清理，连带删掉缓存（约 700MB，主要是浏览器缓存）

存档
  自动保存在本机（%APPDATA%\MemorySanctuary-win_x64.exe）。
  换电脑前请用游戏内「设置 → 导出存档」保存文本，在新机器「导入存档」。
  支持多存档槽，标题界面「读取存档」进入。

更新
  启动后会异步检查新版本，有新版时右下角提示（不阻塞游戏）。
  设置面板里也可以手动「检查更新」。
  新版本直接运行新版安装包覆盖安装即可，存档不会丢。

本版要点（v0.2.11）
  · 界面文案归一：去掉界面里“叙事”这类策划用词（「叙事诗」保留）、
    直角引号改为“”，省略号/括号/冒号统一为中文标点
  · 科技与项目的食物成本现在会正确扣除，并在卡片上显示 🍖 消耗
  · 移除第 36 周起的心跳声（会引起生理不适）
  · 守护者台词去重；能源告急时守护者会说应景的话
  · 维护项目与科技成本普遍下调，单局归档节奏维持在 27% 左右
