记忆圣所 v0.2.12
==================

怎么玩
  安装完成后，从「开始菜单」或桌面快捷方式双击「记忆圣所」即可。
  不需要浏览器、不需要联网、不需要另装运行环境。
  请尽量从“快捷方式”启动：它带有音效自动播放参数，一进门就有 BGM。
  若直接到安装目录双击 MemorySanctuary-win_x64.exe，第一次需要先点一下画面才会出声。

安装信息
  安装位置：默认 %LOCALAPPDATA%\Programs\MemorySanctuary（当前用户目录，不需要管理员权限）
  如果安装时提示缺少 WebView2 运行时，按提示装一下即可（Windows 10/11 通常已自带）。

卸载
  方式一：设置 → 应用 → 已安装的应用 → 记忆圣所 → 卸载
  方式二：开始菜单 → 记忆圣所 → 卸载 记忆圣所
  卸载时会问一句：是否同时删除存档与缓存？
    · 选「否」：保留存档，重装后接着玩（推荐）
    · 选「是」：彻底清理，连带删掉缓存（约 700MB，主要是浏览器缓存）

存档
  自动保存在本机（%APPDATA%\MemorySanctuary-win_x64.exe）。
  换电脑前请用「读取存档」界面底部的「导出存档」保存成文本，在新机器用「导入存档」恢复。
  支持多存档槽，标题界面「读取存档」进入。

退出
  标题画面底部的「退出游戏」按钮可直接关闭程序，也可以点窗口右上角的关闭按钮。
  游戏进度在关键动作后自动保存，关窗前不需要额外操作。

更新
  启动后会异步检查新版本，有新版时右下角提示（不阻塞游戏）。
  设置面板里也可以手动「检查更新」。
  新版本直接运行新版安装包覆盖安装即可，存档不会丢。

本版要点（v0.2.12）
  · 标题画面改版：菱形眼铭牌 + 细金线四角切角，全部按钮统一为同一套形状语言，
    亮/暗两套主题分别校过对比度，1200×750 最小窗口不挤不裁
  · BGM 现在一启动就响：快捷方式带自动播放参数，不必再先点一下；
    同时修复了进入游戏后 BGM 被开场曲顶掉的问题
  · 标题画面新增「退出游戏」按钮
  · 程序图标换成圣所自己的（原本是打包工具的默认图标），文件属性带作者与版权
  · 文档全量校对：README、许可与隐私说明、游戏内「关于」、本说明
