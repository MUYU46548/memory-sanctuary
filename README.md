> 终来之刻，何物当存？

一款末日叙事驱动的资源管理游戏。在文明崩塌后的圣所中，玩家扮演最后的守护者，通过归档文明碎片、管理稀缺资源、探索废墟，决定后世将“看到”怎样的洛斯耶马文明。

本作为**绒花计划**第二部官方游戏。**本项目使用AI辅助开发**。

## 游戏特色

- **叙事驱动**：23 个结局、31 组结局演出场景，碎片化考古拼凑真相
- **资源博弈**：能源、介质、环境、食物四大资源相互制约
- **守护者系统**：5 位守护者，独特技能与性格，好感度影响全局（含背景档案与回忆片段）
- **地表勘探**：派遣守护者探索废墟，获取资源与叙事碎片
- **应急协议**：腐败度管理，权衡短期生存与长期代价
- **AI 助理**：建造项目解锁半价辅助归档（以环境稳定度为代价）
- **士气联动**：士气高低左右随机事件走向，极端士气触发仪式事件
- **NG+ 多周目**：继承解锁内容，发现新条目与新结局
- **无障碍支持**：键盘导航、减少动画偏好、主题切换
- **零外部依赖**：纯原生 HTML5 + CSS3 + Vanilla JS

## 快速开始

### 环境要求

- 现代浏览器（Chrome 90+、Firefox 90+、Edge 90+、Safari 15+）
- 推荐使用本地 HTTP 服务器（避免浏览器安全限制）

### 启动方式

> **面向玩家**：请使用发行页提供的安装包 **`ms-<版本>-setup.exe`** —— 双击安装、开始菜单启动、控制面板可卸载（不需要管理员权限，存档可选择性保留）。无需任何命令行操作。
> 标题画面底部有 **「退出游戏」** 按钮可直接关闭程序；也可直接关窗。
> 请从**桌面 / 开始菜单快捷方式**启动：快捷方式带 BGM 自动播放参数，直接双击安装目录里的 exe 则首次需要点一下才出声。
> 以下本地服务器方式仅面向**开发者调试**，不是玩家的正常启动方式。

```bash
# 开发者调试：在项目根目录执行
python -m http.server 8099

# 浏览器访问
http://localhost:8099
```

端口可自定义，若 8099 被占用可改为其他可用端口。

> 开发注意：直接双击 `index.html` 可能因浏览器安全限制（file:// 下 fetch 被拦截）无法加载数据，请务必通过本地服务器访问。

### 目录说明

| 路径 | 说明 |
|------|------|
| `index.html` + `js/` + `css/` + `data/` + `assets/` + `fonts/` | 游戏本体 |
| `desktop-build/` | 桌面玩家包与安装包工程（Neutralino + Inno Setup）：`build.sh` 出 exe/resources.neu，`build-installer.sh` 出安装包；`dist/`、`installer-dist/` 产物不入库 |
| `scripts/` | 开发辅助脚本（v0.2.8 起历史一次性脚本已清理，均不入库） |
| `立项契约.md`、`开发日志*.md`、`游戏章节拓展.md` | 开发文档（立项约定、开发历史、章节拓展规划），玩家无需关心 |

### 游戏流程

1. **新建游戏** → 选择存档位（1-3）
2. **归档条目** → 消耗能源与介质，保存文明碎片
3. **管理资源** → 应对自然衰减、季节变化、腐败度
4. **地表勘探** → 派出守护者，获取额外资源
5. **启动项目** → 建造设施，获得持续收益
6. **触发事件** → 随机事件影响全局
7. **封印圣所** → 第 16 周后可结束游戏，进入结局

## 游戏玩法

### 资源类型

| 资源 | 上限 | 用途 | 衰减 |
|------|------|------|------|
| 能源 | 150 | 归档操作、项目启动 | ~1.0/周 |
| 介质 | 150 | 归档存储 | ~0.5/周 |
| 环境 | 100 | 维持圣所稳定 | ~0.5/周 |
| 食物 | 80 | 勘探消耗、士气维持 | ~0.3/周 |

> 衰减受士气效率加成影响（0.85× ~ 1.15×），资源归零后可能触发加速衰竭。

### 守护者

| 守护者 | 特长 | 推荐场景 |
|--------|------|----------|
| 缇卡 (Tika) | 歌唱、语言、历史 | 语言/历史类条目、歌声安抚士气 |
| 芬恩 (Finn) | 历史、法律、文献 | 历史/法律类条目、归档建议 |
| 米莎 (Misha) | 生态、勘探、生存 | 生态/勘探地点、食物相关行动 |
| 洛恩 (Lorn) | 工程、维护、能源 | 系统维护项目、能源效率 |
| 埃塞尔 (Ethel) | 宗教、哲学、仪式 | 哲学/宗教类条目、安抚仪式 |

### 结局系统

游戏包含 **23 个结局**，分为：
- **组合结局**（7 个）：基于特定存储室组合的完成度（如「文明之根」= 语言+历史+法律 ≥70%）
- **守护者个人线**（5 个）：好感度达到亲密后触发
- **完成度结局**（3 个）：基于总完成率档位（文明守护者 40%+ / 碎片收集者 30-39% / 微光守护者 5-29%）
- **特殊结局**（5 个）：超越时间（NG+ 第 5 周目）、完美封印、文明抉择、牺牲、遗忘
- **其他**（3 个）：全收集「永恒记忆」、寂静圣所、饥荒降临

## 技术架构

### 设计原则

```
/js/main.js     → 启动、主题切换、数据加载调度
/js/game.js     → 核心状态机（资源、时间、士气、成就逻辑）
/js/game-*.js   → 按系统拆分：事件、勘探、项目、应急、存档、结局、归档、教程、日志
/js/ui.js       → DOM 渲染与事件绑定（不含业务逻辑）
/js/canvas.js   → Canvas 绘图与动画循环（不含 UI 交互）
/js/audio.js    → BGM / SFX 管理（Web Audio API + Audio 元素）
/js/vn.js       → 视觉小说引擎（章节过渡、结局演出）
/js/debug-panel.js → 开发调试面板（发布版密码锁定）
/js/font-loader.js → 霞鹜文楷字体加载与 Cache API 缓存
/data/*.json    → 所有条目、守护者对话、事件、项目、成就
/css/main.css   → 主题驱动样式（CSS 变量）
/index.html     → 单页应用壳
```

### 数据驱动

所有游戏内容存放在 `/data/*.json`：
- `archives.json` — 归档条目（202 条，标题、内容、存储室、成本、解锁条件）
- `vaults.json` — 12 间存储室（容量、主题）
- `guardians.json` — 守护者档案（技能、好感度对话、背景档案、回忆片段）
- `events.json` — 随机/章节/排程事件（79 个，标题、描述、选择、效果）
- `projects.json` — 建设项目（15 个，成本、效果、持续时间）
- `achievements.json` — 成就定义（54 个，类型、阈值、图标）
- `explorations.json` — 勘探地点（34 个，难度、消耗、结果概率）
- `endings.json` / `ending_scenes.json` — 结局定义（23 个）与演出场景（31 组 / 124 条）
- `scenes.json` — 章节过渡剧情场景
- `guardian_events.json` — 守护者个人事件

**禁止在 JS 中硬编码业务数据。**

### 主题覆盖

所有 UI 必须同时适配 `[data-theme="dark"]` 与 `[data-theme="light"]`，颜色通过 CSS 变量引用：

```css
color: var(--text-primary);
background: var(--bg-panel);
border: 1px solid var(--border-subtle);
```

Canvas 绘图颜色同样从 CSS 变量动态读取：

```js
const style = getComputedStyle(document.body);
const amber = style.getPropertyValue('--amber-primary').trim();
```

## 音频系统

采用双轨音频架构：

- **BGM**：使用 `<audio>` 元素播放，支持淡入淡出切换
  - 默认音量 80%，可在设置中调整
  - 场景切换：标题 → 游戏 → 游戏中期 → 游戏后期 → 结局
- **SFX**：使用 Web Audio API 合成，零外部资源依赖
  - 默认音量 100%
  - 包含：归档成功、资源警告、勘探派遣、事件触发等

**静音控制**：
- 顶部栏静音按钮（全局）
- 设置面板：BGM 音量、音效音量、全局静音
- 静音状态写入 `localStorage`（`memory-sanctuary-settings`），重启后保留

**自动播放（仅桌面版）**：Chromium / WebView2 的自动播放策略默认要求一次用户手势，页面层无法绕过。桌面版的快捷方式与安装后启动会带参数
`--edge-webview-switches=--autoplay-policy=no-user-gesture-required`，让 BGM 一启动就出声；
该参数只作用于本程序进程，不写系统环境变量。玩家若绕过快捷方式直接双击 exe，
则退化为首次点击/按键后出声（`js/main.js` 的捕获阶段解锁兜底）。

## 调试与开发

### 快捷键

| 快捷键 | 功能 |
|--------|------|
| `Space` | 跳过回合（游戏内） |
| `Esc` | 关闭弹窗（含确认弹窗） |
| `Ctrl+Shift+D` | 切换调试面板 |

> 全局静音没有键盘快捷键，请用顶部栏静音按钮或设置面板。
> 标签页切换也没有数字键快捷键（归档 / 守护者 / 存储室 / 科技 用鼠标点击）。

### 调试面板

浏览器中按 `Ctrl+Shift+D` 打开，包含五大功能：

1. **资源修改**：实时调整能源/介质/环境/食物
2. **时间跳转**：跳转到指定周数（1-48）
3. **事件触发**：手动触发指定事件或强制随机事件
4. **成就操作**：解锁指定成就、重置所有成就
5. **状态导入/导出**：导出当前 state JSON、导入状态、清除存档

> 发布版（`DEBUG=false`）调试面板已锁定，需输入调试密码 `sanctuary-dev-2026`（见 `js/debug-panel.js` 的 `DEBUG_PASSWORD_HASH`）。开发调试请将 `js/main.js` 顶部 `DEBUG` 设为 `true` 免密打开。

node -c js/game.js && node -c js/ui.js && node -c js/main.js && node -c js/canvas.js && node -c js/audio.js && node -c js/vn.js

## 多周目系统

完成任意结局后解锁多周目模式：

- **继承内容**：已解锁的归档条目、成就、守护者终局记忆
- **新增条目**：多周目专属条目（需满足特定解锁条件）
- **结局扩展**：多周目可触发隐藏结局
- **进度追踪**：累计归档数、最佳记录、周目计数

## 更新日志

### v1.0.0（2026-11-15）

正式版。这一版把「资源明明够却归档不了」「一次勘探都没派过全员却都在疲劳」「应急协议的音效从来没听到过」这三类反复出现的问题从根上修掉，并重做了文明画像的判定口径。

- **归档判定与扣费统一口径**：以前「能不能点」用基础消耗判，真实扣费却按主题契合 −20%、食物归零时能耗 +20%、介质豁免翻倍算，两边永远对不上。现在只有一份数：按钮直接写清原因（资源不足 / 容量不足 / 介质耗尽），列表与确认弹窗显示的就是真实扣费。存储室装满也会提前说明，不再点了才报。
- **勘探疲劳与空队伍**：「紧急勘探」协议不再在激活的瞬间给全员上疲劳（只有真出发的人才疲劳，且封顶 1 周）；没选人时按钮禁用，控制台也绕不过去。
- **应急协议音效重做**：旧的两个音全在 40–200Hz，比背景音乐低 9–14dB，实际等于没响。现在补了 1.1kHz 上电确认音与 1kHz 三连警报，实测响度与归档风铃齐平。
- **速记有真实代价**：改为环境稳定度 −2（不再推进时间，等于每周多一次归档机会），一周目归档上限从 48 条提到 96 条。
- **文明画像重做**：分母改用本周目可归档的条目，档位按实际可及区间重标；8 种组合画像（新增「巢与圣所」）现在真的会随打法出现，而不是每局都同一张。
- **清理从未生效的规则**：「主题不合 +30%」全库 200 条命中 0 条、从未生效，已删除。
- **内容修复**：找回「轨道交通中枢」的两条地表碎片（此前被误删，派出机器人拿不到东西）；「建筑与工程」存储室扩到 160，该室条目不再装不下。
- **文案**：DLC 数据里的直角引号、ASCII 引号与界面禁用词统一到文案规范。

### v0.2.13（2026-11-06）

- **桌面版存档不再丢**：根因是 Neutralino 每次启动随机端口，页面 origin 每次都变、而 localStorage 按 origin 隔离。现在固定端口（`neutralino.config.json` 的 `port` + 安装包快捷方式 `--port=45999` 双保险），并给存档加了一层文件镜像 `%APPDATA%\MemorySanctuary-win_x64.exe\saves\`，启动时若 localStorage 为空会自动从文件恢复。
- **退出前先存档**：点「退出游戏」和右上角 X 关闭窗口都会先写盘再退出（后者靠 `windowClose` 事件 + `exitProcessOnClose: false`）。
- **双主题可读性按 WCAG 实测重校**：暗色主题 `--text-dim` / `--danger` / 守护者旁白色 / 三个存储室强调色全部提亮，亮色主题对应压深；实测主界面低对比文字从暗色 32%、亮色 46% 降到 0。附带把 9.4px / 10px 的超小字号抬到 11px 起。
- **窗口左上角图标**：config 的 `applicationIcon` 只写进 exe 资源，运行期没人给窗口设图标（`WM_GETICON` 取不到句柄），改为 `Neutralino.window.setIcon('/resources/assets/icons/icon-32.png')`。
- **覆盖安装认目录**：安装包固定按用户安装（不再提权，避免安装记录落到另一个注册表 hive），并在装前自动探测已有安装目录（注册表两个 hive + 常见路径 + 各盘符）。

### v0.2.12（2026-11-05）

- 标题画面改版（菱形眼铭牌 + 细金线四角切角），亮/暗双主题分别校准，1200×750 无溢出。
- 桌面版 BGM 启动即响（启动参数 `--edge-webview-switches=--autoplay-policy=no-user-gesture-required`），修掉待播队列把进游戏 BGM 顶掉的问题。
- 标题画面新增「退出游戏」；exe 图标与文件属性换成项目自己的。
