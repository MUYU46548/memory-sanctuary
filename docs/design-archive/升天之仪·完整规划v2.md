## 一、玩家的一局，逐段

**总时长 4–5 小时。三幕。**

### 第一幕 · 装得满（90 分钟）

| 分钟 | 在哪 | 发生什么 |
|---|---|---|
| 0–8 | 地表 | 开局。顶灯两盏。瑟兰坐在台基边上，不看你。走近她 → 她说一句不带任务的话。走近装配台 → 空的，还没有晶体。 |
| 8–30 | 避难所 | 第一次走遍六个房间。每个房间至少三件能看的东西。认识五个人。**没有任务提示，只有人**。 |
| 30–55 | 避难所 | 过两周（睡觉推进）。中间有三个事件，都是 NPC 走过来找你。 |
| 55–65 | 配给室 → 地表 | 拿到晶体（管配给的给你，要你签一份册子）。上楼。 |
| 65–83 | 装配台 | 六件零件，六条读数，三个人各补一个盲区。**20 分钟的手工活**。 |
| 83–90 | 发射 | 判定、点火、上去或坠回。然后回程，字幕。 |

### 第二幕 · 装不满（100 分钟）

开局直接在地表，天更暗。**走进避难所，床位空了一半**，有人已经不在原来的位置。

- 缺谁：由第一幕末尾的一个决定 + 你在配给册上签了什么决定。**不是随机。**
- 装配台这次零件不全：库存从第一幕剩下的里出。
- 事件更硬：投票、切割闸门、最后一支针。

### 第三幕 · 凑（70 分钟）

只有 3 个人。**没有人来台基下送行。**
装配台的零件库全换：拼合晶体、布条、残骸拼接。六项里必有超限。
发射判定改成"只要离地就算"。

## 二、场景清单

### 地表（一场）

| 物件 | 在哪 | 交互 | 什么时候变 |
|---|---|---|---|
| 发射架 + 装配台 | 中央 | E → 打开装配台 | 没有晶体时是空的 |
| 台基 | 南侧 | 看 → 描述焊缝、灰、羽毛 | 每幕多一层灰 |
| 瑟兰的凳子 | 台基边 | 说话 | 第二幕她可能不在 |
| 北边的路 | 边缘 | 看 → 沙、风 | 第三幕能看到远处有烟 |

### 避难所（六间）

**1. 闸门**
- 守闸人（不出现，只有声音，在门后那道小窗前）
- 贴着门听 → 风声，像有人在磨牙
- 无线电 → 第一幕是空的；第二幕有人敲三下；第三幕没有电
- 门上的划痕：每幕多几道

**2. 配给室**
- 墙上的册子：写着今天的份数，划掉过的行
- 管配给的人（他每天早上在这里）
- 存粮架：看一眼就知道还能撑几周
- **晶体柜**：锁着，钥匙在管配给的人手里

**3. 居住区**
- 床位：第一幕 28 张铺；第二幕 14 张；第三幕 3 张叠在一起
- 薇希（在这里练歌，哼到一半就停）
- 孩子（在地上画东西。第一幕画星星；第二幕画发射架；第三幕不画了，坐在画前面）
- 墙上的刻字（三处，每幕能看清更多）

**4. 锅炉房**
- 三号机：在响 / 不响
- 粉笔数字：剩余电量的估数，每天有人改
- 卡穆（有时在修，有时不在）
- 烧剩的木头、铁皮、半罐润滑脂

**5. 医务室**
- 铁盒里的针剂：第一幕两支；第二幕一支；第三幕空盒
- 病历本：只有七页有人写过
- 母亲（孩子病了她才来，否则不在）
- 一张永远空着的床

**6. 圣所入口**
- 挖了一半的通道，尽头是一扇没装上的门
- 十二间存储室只开了一间，里面是空的
- 地上有粉笔画的图：他们本来打算怎么搬
- 第三幕这里能听见风，因为闸门被拆了

## 三、人物

| 人 | 常在哪 | 他的作用 | 状态变化 |
|---|---|---|---|
| **瑟兰** | 地表台基边 | 听共振；唱；告诉你她唱不动了 | 一幕：在；二幕：可能在，也可能不在了；三幕：不在 |
| **卡穆** | 锅炉房 / 台基下 | 复检隐性缺陷；做加固环；改过一个数 | 一幕：在；二幕：如果你让他去过地表，他不在了 |
| **薇希** | 居住区 | 手小能装到底；试唱；索引 | 一幕：在；二幕：在（或者你派她去了）；三幕：只剩她或只剩你 |
| **守闸人** | 闸门后 | 唯一的消息来源：外面还剩多少人 | 三幕全程在，但三幕末期不再回答 |
| **管配给的** | 配给室 | 事件发起者；也想要你的位置；晶体的钥匙 | 二幕：可能掌权；三幕：不在了 |
| **母亲** | 医务室 / 居住区 | 孩子病了她才出现 | 孩子死了她就不说话了 |
| **孩子** | 居住区 | 环境叙事：画的东西一局里会变 | 一幕画星星；二幕画发射架；三幕不画 |

**每个人都有一件跟任务无关的习惯**（叠外套、数螺母、反复擦同一块铁）。这是他们像人的唯一办法。

## 四、事件清单（三幕 28 个）

**规则：不用弹窗。事件发生时，那个人走到你面前，或者已经在那个房间等你。**

### 第一幕（12 个）

| # | 谁来找你 | 在哪 | 什么事 | 选项 → 后果 |
|---|---|---|---|---|
| 1 | 管配给的 | 配给室 | 存粮少了三份，他知道是谁 | 公开处理／私下补／不管 → 人心 −8／+4／−3 |
| 2 | 母亲 | 医务室门口 | 孩子咳了两天，只剩两支针 | 一人一支／先救重的／留着等 → 人心／民心 |
| 3 | 卡穆 | 锅炉房 | 三号机绕组烧穿，修要三天人手 | 修／拆了换灯／放着 → 电／人心 |
| 4 | 四个年轻人 | 闸门 | 他们要走，要带走一份配给和三天的水 | 让走／拦住／让走多给水 → 人口／人心 |
| 5 | 管配给的 | 配给室 | 他要求配给由大家定 | 同意／拒绝／三人加你 → **决定第二幕的权力结构** |
| 6 | 守闸人（声音） | 闸门 | 无线电有人敲三下 | 派人去／回敲／关机 → 零件／人心 |
| 7 | 瑟兰 | 地表台基 | 她说她唱不动了，问你还要不要她唱 | 让她唱／让她别唱／找薇希替 → **决定第一枚的发射结果** |
| 8 | 孩子 | 居住区 | 他给你看他画的东西 | 蹲下来看／说很好看／走开 → 三幕里他画什么 |
| 9 | 有人（无名） | 居住区最里面 | 有人自折了翅膀，还活着，不说话 | 绑起来喂／让他自己决定／挪到单间 |
| 10 | 薇希 | 居住区 | 她问你：能不能让她唱一次 | 让她试／不让她试 → 容量 ±20% |
| 11 | 卡穆 | 锅炉房 | 他说他改了检修清单上的数 | 追下去／装作没看见 → 加固环／隐性缺陷 |
| 12 | 管配给的 | 配给室 | 最后一个晚上，问你签不签那份册子 | 签／不签 → **晶体到手／拿不到** |

### 第二幕（10 个）

主题从"分配"变成"谁走、谁留、谁动手"。

1. 配给册被人撕了（谁撕的？查 / 不查）
2. 闸门被热能切割器试过一次（守 / 加固 / 搬走贵重东西）
3. 黑市：有人拿净水芯片换针剂
4. 第二避难所的无线电没人接了
5. 有人要求你下台
6. 卡穆（若在）说他手上没料了
7. 薇希（若在）说她能唱完，但会破
8. 母亲（若孩子还在）要你保证下次带药回来
9. 有人在墙上写你的名字，旁边划了一道
10. 最后一个晚上：谁留下来守门

### 第三幕（6 个）

只剩几个人，事件变少变短。

1. 有人一大早就坐在台基下面，不说话
2. 最后一根羽毛的事
3. 圣所入口的风声变大了
4. 有人在拆发射架的螺丝（想拿去做别的）
5. 最后一个晚上，没有人来问你任何事
6. 出发前，回头看一次

## 五、装配的三次

| | 零件库 | 约束 | 时长 |
|---|---|---|---|
| **第一枚** | 十件（标准晶体/加大、厚垫/薄垫、旧壳/新壳、涂层、环、加固环、两种系羽） | 六位六读数；必须删一段内容或找大晶体 | 20–25 分 |
| **第二枚** | 由第一幕库存决定（通常五到七件），**稀缺件可能没有** | 缺件就得拿替代品顶，每一项都贴红线 | 20–25 分 |
| **第三枚** | 六件残骸件（拼合晶体、布条、残骸壳、刮下来的涂层、铁丝环、最后一根羽） | **必有超限项**；只认"瓶子离地" | 15–20 分 |

三个人各补一个盲区（卡穆：隐性缺陷；瑟兰：共振；薇希：容量），缺人则盲区永久打开。

## 六、结局

由**三次发射结果** + **保住的人**决定，八个：

| 结局 | 条件 |
|---|---|
| 三次都算数 | 三枚全离地且内容完整 |
| 两次算数 | 任两枚 |
| 一次算数 | 任一枚 |
| 一次都没有 | 三枚全坠 |
| 第一枚完美，后两枚全废 | 第一枚完美 + 后两枚坠 |
| 第三枚只有你 | 第三枚离地，且无人在场 |
| 一个人都没死 | 两幕都没有人走、没有人死（几乎不可能） |
| 有选择的瓶 | 兜底 |

每个结局三段：**当下**（发射后那十分钟）、**算不算数**、**一千年后的读法**。

## 七、体量账（这一节决定它到底是 30 分钟还是 5 小时）

上一版我写「60–80 个观察点、300–400 个对话节点」——**那个数字只能撑 30 分钟**。用户看两眼就判断出来了，是对的。重算：

### 目标拆解

| 段 | 分钟 | 靠什么填 |
|---|---|---|
| 探索（三幕走遍七个房间，每幕都变） | 150 | 交互点 |
| 对话（七个人，每幕状态不同） | 90 | 对话节点 |
| 装配（三次） | 65 | 装配台 |
| 发射 + 结算（三次） | 25 | 过场 |
| **合计** | **330 分钟（5.5 小时）** | |

### 反推数量

| 项 | 我上一版写的 | 实际需要 | 倍数 |
|---|---|---|---|
| 观察点 / 可交互物 | 60–80 | **420**（7 房间 × 3 幕 × 20） | **6×** |
| 对话节点 | 300–400 | **900**（7 人 × 3 幕 × 40 + 事件内嵌） | **2.6×** |
| 事件链 | 28 个单点 | **28 条 × 6 节点 = 168** | **6×** |
| 总交互次数 | ~400 | **~1500**（× 15 秒 ≈ 375 分钟） | **4×** |
| 文本 | 6–8 万字 | **18–24 万字** | **3×** |

**关键不是房间更多，是每个房间更深、而且三幕都要重走一遍。**

一个房间：
- 第一幕：20 个交互点（第一次进来，什么都要看）
- 第二幕：12 个新的（房间变了，旧的回看有变化）
- 第三幕：8 个新的（只剩几样东西）

7 个房间 × 40 = **280 个交互点**，加事件里的 → 420。

### 一个房间的粒度（配给室，第一幕 20 个）

1. 墙上的册子·封面（写着年份，被人改过）
2. 册子·第一页（二十八人的名字）
3. 册子·今天那一页（份数被划掉一半）
4. 册子·最后一页（空白的，边缘有压痕）
5. 存粮架·第一层（合成藻块，数得出来）
6. 存粮架·第三层（空的，有老鼠咬过的印）
7. 存粮架·最底层（一袋没见过的东西）
8. 晶体柜·锁（钥匙不在这）
9. 晶体柜·柜门上的划痕
10. 桌上的笔（笔尖劈了）
11. 地上一张撕碎的纸（拼起来是一份名单）
12. 门框上的身高刻痕（三代人的）
13. 墙角的秤（砣少了一个）
14. 窗（其实是个通风口，能看见第一层的灯）
15. 管配给的人·他在写字
16. 管配给的人·他的手套（右手那只破了）
17. 管配给的人·他背后的椅子（有人坐过，垫子还热）
18. 墙上的配给表（贴了三层，最下面那层是灾前的）
19. 一盏不亮的灯（灯泡被拧走了）
20. 门后的记号（每过一周加一道，已经二十六道）

**二十个里，只有 3 个推进主线。其余十七个是让这个地方存在。**

第二幕同一个房间：「存粮架·第一层」变成完全空的；「门框上的刻痕」多了两道新刻的，比原来的高——因为刻的人换了；「管配给的人·他的椅子」空了，垫子凉了。

### 为什么这个账必须现在算

内容写下去之后，房间是改不动的。**420 个交互点是一个房间一个房间写出来的，不是加量加出来的。** 所以每个房间的 40 个点必须在动笔前定清单，否则写到第五个房间就会开始重复。

## 七之二、体量从哪来（同类游戏的做法，不是加地图）

我一直用「房间数 × 交互点」来算体量，这是错的。同类游戏都不这么做。

| 游戏 | 场景有多少 | 为什么能玩几十小时 | 机制 |
|---|---|---|---|
| **Disco Elysium** | 一个街区 | 每个 NPC 有十几到几十个话题，**话题由你的技能、思维、看见的东西解锁** | 同一句话，带着不同认知回去问，回答完全不同 |
| **Pentiment** | 一个镇 | 三次时间跳跃（1518/1525/1533），**同一个地方、同一批人，全变了** | 重访 + 变化 |
| **Outer Wilds** | 一个小星系 | 22 分钟循环，**带着新知识回同一个地方，看到的东西不一样** | 重访 + 认知 |
| **Obra Dinn** | 一艘船 | 同一个场景反复进入，每次解锁几个死亡片段 | 重访 + 拼图 |
| **Papers, Please** | 一个窗口 | 每天同样的流程，**每天换规则** | 重复 + 变奏 |

**共同点只有三个：重访、变化、话题的层次。** 没有一个靠"更多地图"。

### 所以本作的体量必须从这三处来

**一、看见的东西 = 问人的话头。**

观察不是"读一段描写就完了"。每看见一样东西，你**多了一个能问的问题**。

- 看了册子今天那页被划掉一半 → 才能问管配给的「为什么少了十份」
- 看了门框上的刻痕 → 才能问守闸人「以前这里有孩子？」
- 看了柜门的划痕 → 才能问卡穆「有人试过撬这个？」

**这就是把房间和对话缝在一起的办法**：房间提供话头，对话消耗话头，对话的答案又解锁新的话头。体量因此是指数的，不是线性的。

**二、每个人有三层话。**

| 层 | 条件 | 内容 |
|---|---|---|
| **表面** | 无 | 敷衍的回答 |
| **第二层** | 你带着某个话头来问 | 他认真了 |
| **第三层** | 你带着两个话头 + 已经问过第二层 | 他告诉你真话 |

7 个人 × 20 个话题 × 2.5 层 ≈ **350 段对话**。这不是靠"多写"，是靠"层"翻出来的。

**三、同一个地方，三幕都不一样。**

一条走廊第一幕有六个人，第二幕两个，第三幕空的。**空本身就是内容**——玩家会自己想起第一幕这里站着谁。

### 重算后的数字

| 项 | 数量 | 怎么来的 |
|---|---|---|
| 观察点 | 240 | 7 房间 × 3 幕 × 平均 11 个真正可点的 |
| 话题 | 140 | 7 人 × 20 |
| 对话段 | 350 | 话题 × 层 |
| 事件链 | 28 条 × 6 节点 | |
| 装配 | 3 次 × 25 分钟 | |
| **一局走完约 60%** | **4.5–5 小时** | |
| **全内容** | **7 小时** | 二周目才看得全 |

**注意最后一行：全内容比一局长 40%。** 这是重访类游戏的核心——第一遍看不全，你也知道自己看不全，因为有些话你问不出来。

### 样板已实装（配给室 + 居住区 · 第一幕）

`data/dlc/ascension/rooms/*.json` · 代码里没有一句台词。一间房一份 JSON，加房只加一行文件名。

| 项 | 实装 |
|---|---|
| 房间 | **2 间**（配给室、居住区），都是带门带墙的屋子，各 20+ 个观察点 |
| 观察点 | **45**（配给室 20 + 居住区 25：12 个物件 + 薇希 3 眼 + 孩子 2 眼） |
| 话头 | **28**（26 来自观察，2 由第三层发放） |
| 人物 | **3 个**（管配给的 / 薇希 / 孩子），12 个话题 |
| 话题 | **12** × 3 层 = **36 段**，全部可问到第三层 |
| 跨话题成环 | 「椅子」第三层 → 新话头「原来管配给的是个女人」→ 打开「晶体柜的钥匙」第三层 |
| **跨房间成环** | 居住区「薇希谱夹里的配给单」→ 回配给室问「今天发几份」第三层，他才说出把口粮藏在第四层 |
| 校验 | `node scripts/check_ascension_room.js`（全部房间合并校验）→ 无断链、无问不到的层、无指向不存在的人 |

看见与问都不花行动点。**45 眼 → 28 句能问出口的话 → 36 段回答。**
其余五间房照同一形状写：写 JSON + 加进 `ROOM_FILES` + 跑一次校验。
