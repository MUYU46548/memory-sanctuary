## 一、这是个什么游戏

**一句话：** 你在一年里发射三枚瓶子。第一枚装满，第二枚装不满，第三枚只剩你自己。

**类型：** 精密装配 + 仪式流程。对标 The Room（手感）+ 装机模拟（取舍）+ 冰汽时代（调度）。
**不做：** QTE、倒计时、反应速度、随机判定。

| | |
|---|---|
| 总时长 | **3.5–4.5 小时** |
| 结构 | 三枚瓶子 + 两段间奏 = 五段 |
| 每段时长 | 60–75 / 15–20 / 60–75 / 15–20 / 50–60 分钟 |
| 视角 | 第一人称，执仪者本人 |
| 美术 | 零图片，全 SVG 几何剖面 |
| 音频 | GM 音色 + FluidSynth 合成（颂歌用 GM 53 Voice Oohs） |

## 一之二、时间线定位（2026-11-12 核查设定库）

**先给结论：设定库不需要修。**

三条词条看起来不一致，但重新读一遍，它们可以同时成立：

| 条目 | 说法 | 读法 |
|---|---|---|
| `突触震动.md` | 第 **1–2 个月**「初期反应」里写了「各地翼族举行了升天之仪」 | 记的是**开始**——零星、自发、各地分别 |
| `萨拉达斯.md` | 第 **9–18 个月**：转入地下；建造记忆圣所；举行升天之仪 | 记的是**集中期**——成规模、有组织 |
| `洛斯耶马文明.md` | 第 9–18 个月：避难计划启动，记忆圣所建造，升天之仪开始举行 | 同上 |

**「记忆圣所建造」也是同一种情况**：第 1–2 个月动工，第 9–18 个月是主体工程。两条都没错，只是粒度不同。

我一开始判成「正典内部冲突、要修 vault」，是因为把「开始」和「集中期」当成了互斥的断言。**这个判断收回。**

**对本设计的实际约束只有一条：升天是一个跨越第 1–18 个月、并延续到社会崩溃之前的持续行为。**（四十余枚成功 + 二十余枚失败，全行星多个发射点，不可能挤在九个月里。）

三枚据此铺开，落在「集中期之后、崩溃之前」：

| 段 | 灾难后 | 正典状态 |
|---|---|---|
| 第一枚 | 第 18 个月 | 中期挣扎末期：羽毛脱落病变，「自折翅膀」意象出现 |
| 冬天 | 第 19–22 个月 | 地表回不去了，配给开始按人划 |
| 第二枚 | 第 23 个月 | 条约还在，第一个粮食工厂即将停机 |
| 间奏 | 第 24–30 个月 | 进入晚期崩溃第一阶段：闸门开始上锁 |
| 第三枚 | 第 30 个月 | 第 2 年末，公约的裂缝已经能看见 |

**四处要照顾到的文本：**

1. **冬天的灾祸不能写暴动和切割痕。** 那是第 3–4 年的特征，现在是第 2 年。改成：配给按人划、羽毛脱落、有人自折翅膀、有人驾飞船走。（现有文本已核对，没有写越界的东西。）
2. **第三枚那根羽毛要交代清楚。** 第 2–3 年「幸存者羽毛脱落病变」，但执仪者是「羽毛仍相对完整者优先」。所以是**他身上最后一片没有掉的**。（已改。）
3. **四十余枚不是一个人发的。** 是全行星多个发射点的总和，本设计只是其中一个发射架的三枚。

   **已定（2026-11-12 作者拍板）：第三枚就是最后一批。** 不挪时间，改在文本里承认。第三枚结局里加了两句：

   > 这是最后一个发射架。北边那两座，去年冬天就没有声音了。
   > 你发的是第四十六枚。没有人知道第四十七枚在哪里。

   这两句同时干了三件事：把「最后一批」钉死；把「四十余枚」的账对上（玩家发的是第 46 枚）；把「别处也在发」这个背景交代掉，不用在别处再解释。
4. **执仪者很可能参与过建记忆圣所。** 两条词条都把「建圣所」和「升天」放在同一时期、同一批人手里。这是两个模式之间天然的一根线，后面可以拿来用。

> 另：正文里「装配从 6 槽扩到 12 槽」曾经被我说成「正典给的」，**那句作废**。十二间存储室是记忆圣所的建筑结构（十二类记忆各一间），和祈愿瓶的载荷格没有关系。祈愿瓶的载荷正典明写是**四样**（基本信息 / 语言词典 / 艺术与哲学文本 / 问候音频）。12 槽如果做，是设计选择，不是正典依据。

## 二、五段结构

### 第一枚 · 装（60–75 分钟）

**在场 12 人，三个有名有姓。**

九阶段：检修 → 拆封 → 装舱 → 拭羽 → 歌者 → 抬台 → 诵唱 → 发射 → 割羽。
其中四个阶段是装配台（检修、装舱、拭羽、抬台准备），其余是流程与视听。

**做法：** 十件零件里选六件装上，四个内容段里选着塞进晶体。三个人的能力能补全你的盲区。

**这一段的主题：你什么都不知道，但一切都还不算太坏。**

### 间奏一 · 分（15–20 分钟）

第一次发射后四个月。地下。库存见底。

**玩法：调度。** 一张桌子、三个人、几件待办：
- 谁去地表找零件（可能回不来）
- 谁留下保养设备
- 要不要拆掉上一枚的备用件

**这一段的主题：你开始用人的命换零件。**

派出去的人有概率回不来。回来的带什么，由你去的地方决定。**这段的选择直接决定第二枚谁不在。**

### 第二枚 · 补（60–75 分钟）

**在场 8 人。**

缺的人不在了。缺谁，取决于间奏一。

**玩法：装配 + 补位。** 少了一个人，他的活你得自己干：
- 卡穆不在 → 隐性缺陷全盲，加固环做不出来，你只能凭手摸
- 薇希不在 → 晶体装不到位，容量 −20%，你得在更小的空间里塞内容
- 瑟兰不在 → 共振变成盲区，你听不出问题

**这一段的主题：你在替别人干活，而你干得不如他们。**

### 间奏二 · 守（15–20 分钟）

第二次发射后六个月。避难所空了。

**玩法：守。** 没有大决定，只有小事：
- 有人病了，要不要用掉最后的药
- 有人在墙上刻字，你看着
- 有人不说话已经十一天了

**这一段的主题：剩下的人不需要你救，只需要你在。**

### 第三枚 · 凑（50–60 分钟）

**只剩你和一两个人。**

**玩法：装配 + 凑。** 零件不全，你得用替代品：
- 没有涂层 → 用上一枚的残骸刮下来的旧料，厚度不可控
- 没有加固环 → 用金属丝绑，共振升高
- 没有完整晶体 → 两块拼起来，容量 −15% 且有裂纹风险

**这一段的主题：每个选择都是妥协，而你只能选一个。**

## 三、人物系统（核心）

三个人各有一种**感官**，对应装配里三个维度。他们不是 NPC，是**工具**。

| 人 | 感官 | 能补的盲区 | 怎么发现他能干这个 | 他不在之后 |
|---|---|---|---|---|
| **卡穆** · 发射技师 | **手** | 螺纹、垫圈、金属疲劳 | 看见他在数螺母，数了两遍 | 隐性缺陷全盲 |
| **瑟兰** · 年长歌者 | **耳** | 共振、台基、密封的漏气声 | 她经过台基时会停一下 | 共振变盲区 |
| **薇希** · 年轻歌者 | **手小** | 最深处那格、晶体内部裂纹 | 她的手比你的小一圈 | 容量 −20% |

**"理解"怎么发生：** 不是读档案，是看见。她抬手时按了一下锁骨；他数螺母数了两遍；她经过台基时停半步。这些是**正文里的可点词**，点一下就记下。记下了，才能请他们动手。

**请他们动手是有代价的**：卡穆加固要 400 克备用金属；瑟兰要听，得让台基静下来（停一次流程）；薇希伸手，会把手划破（下一段她状态差）。

## 四、装配数值体系

六个**显性读数**（玩家能算）：

| 维度 | 基准 | 阈值 | 由什么影响 |
|---|---|---|---|
| 总质量 | — | ≤ 78.0 kg | 每个零件 + 内容 |
| 重心偏移 | 1.8% | ≤ 1.5% | 固定环（−0.8） |
| 舱压 | 0.978 | ≥ 0.990 | 缓冲垫、晶体规格 |
| 耐烧蚀 | — | ≥ 5.0 mm（旧规程）／≥ 4.0（新配方） | 壳体 + 涂层 |
| 共振 | 0.35 | ≤ 0.45 | 缓冲垫（−0.12）、系羽方式（+0.18） |
| 内容容量 | — | 晶体容量 | 内容段占用 |

三个**隐性缺陷**（读数显示正常，但会输）：

| 缺陷 | 谁发现 | 表现 |
|---|---|---|
| 固定环螺纹滑丝 | 卡穆复检 | 上升段松脱，轨迹偏 |
| 垫圈老化 | 卡穆复检 | 舱压缓慢泄漏 |
| 晶体内部裂纹 | 薇希伸手 | 上升段振动时裂开 |

**这是整个设计的支点：六条读数全绿，你照样会输。** 因为读数里没有一项叫"螺纹"。

**知识换空间，不换选项**：知道了"新配方 4.0 起算"，才敢用轻壳体（46 kg），才装得下全部四段内容——但那一路上每一项都贴着红线。

已验证的四套方案：

| 方案 | 读数 | 结果 |
|---|---|---|
| 标准件 + 小晶体 | 70.82 / 0.993 / 5.30 / 0.41 / 100 满 | 能上天，**必须删掉一段内容** |
| 大晶体 + 新壳体 + 涂层 | 75.22 / 0.991 / 4.30（需知新规程）/ 0.41 / 115 | **四段全装**，四项临界 |
| 大晶体 + 旧壳体 | 77.22 / 0.991 / 5.30 | 也能全装，但只剩 0.78 kg 余量 |
| 薄垫偷轻 | 69.32 / **0.973** / 5.30 / **0.48** | **双超限，必坠** |

## 五、内容容量系统

晶体里装四段文明：

| 内容 | 容量 | 质量 |
|---|---|---|
| 四种语言的完整词表 | 60% | 2.0 kg |
| 《翼神升天颂》全本 | 20% | 0.8 kg |
| 童谣与家庭录音 | 15% | 0.4 kg |
| 多频率问候音频 | 20% | 0.6 kg |
| **合计** | **115%** | 3.8 kg |

**装不下。** 玩家必须亲手删掉一段，或者去找那块更大的晶体，然后承担重量。

而"知道颂歌后半段只口传"，就能选"只装前半"（10%），省下 10%——**知识换来的是容量，不是选项。**

## 六、结局矩阵

结局由**三枚的状态** + **保住的人**决定，不是分数。

| 优先级 | 结局 | 条件 |
|---|---|---|
| 高 | **三次都算数** | 三枚全成功，且三个人都活到第三次 |
| 高 | **两枚算数** | 任意两枚成功 |
| 中 | **第一枚完美，后两枚全废** | 第一枚成功且四段全装，二三枚都坠 |
| 中 | **第三枚只有你** | 三枚都发射了，只有最后一枚成功，且无人在场 |
| 中 | **一次算数** | 只一枚成功 |
| 低 | **三次都没有算数** | 三枚全坠 —— 但瓶子都飞了 |
| 低 | **一个人都没死** | 特殊：间奏一和间奏二都没派人去地表，且三枚全成功（几乎不可能，但存在） |
| 兜底 | **有选择的瓶** | 其余 |

每个结局写三段：**当下的场景**、**这一次算不算数**、**一千年前的读法**。

## 十、三个真实风险

1. **隐性缺陷会被当成 bug。** 玩家输在看不见的地方，第一反应是"游戏坏了"。必须让"输"的文本明确说清是谁告诉过你、你没听——不能只说"环松了"。
2. **第二枚缺人之后，装配会变难而不是变有意思。** 如果"补位"只是数值惩罚，那就退化成难度曲线。补位必须带来**新的操作**（比如自己伸手进深处，要拖三次才对位）。
3. **第三枚"凑"很容易变成一堆劣质零件的排列组合。** 必须给每件替代品一个具体的来历（"这是从第一枚的残骸上刮下来的"），否则就是数值表。
